# เขียนบทความบน tempKAEW

คู่มือนี้สำหรับตอนเขียนโพสต์ใน Blogger ธีมจัดรูปแบบให้เนื้อหาทั่วไปอยู่แล้ว สิ่งที่ต้องใส่เองมีอย่างเดียวคือปุ่มดาวน์โหลด

## ปุ่มดาวน์โหลด

ลิงก์ธรรมดาจะเป็นตัวอักษรสีส้ม มีขีดใต้ ปุ่มดาวน์โหลดจะเกิดขึ้นเมื่อลิงก์มีคลาส `download`

ในตัวแก้ไขโพสต์ให้สลับไปมุมมอง **HTML** แล้ววางบล็อกนี้แยกจากย่อหน้า ไม่ต้องใส่ปุ่มนี้กลางประโยค

```html
<a class="download" href="https://example.com/larust-app.zip">
  <span>larust-app.zip<small>2.4 MB</small></span>
</a>
```

การ์ดจะมีไอคอนดาวน์โหลด ชื่อไฟล์ ขนาดไฟล์ และป้ายชนิดไฟล์ทางขวา

ขนาดไฟล์ไม่บังคับ ถ้าไม่ต้องการบรรทัดที่สอง ใส่แค่ชื่อไฟล์

```html
<a class="download" href="https://example.com/notes.pdf">notes.pdf</a>
```

ป้ายชนิดไฟล์อ่านจากท้าย URL

| ท้ายลิงก์ | ป้าย |
| --- | --- |
| `.zip` | ZIP |
| `.rar` | RAR |
| `.7z` | 7Z |
| `.gz` หรือ `.tgz` | GZ |
| `.pdf` | PDF |
| `.dmg` | DMG |
| `.exe` | EXE |
| `.apk` | APK |
| `.mp3` | MP3 |
| `.mp4` | MP4 |
| `.png` `.jpg` `.jpeg` `.webp` | IMG |
| อื่นๆ เช่น Google Drive | FILE |

ถ้า URL มี query ต่อท้าย เช่น `file.zip?dl=1` ป้ายจะเป็น FILE เพราะนามสกุลไม่ได้อยู่ปลายสุดของลิงก์

หลังวาง HTML แล้ว อย่าสลับกลับไปมุมมองเขียนแล้วจัดรูปแบบลิงก์นั้นซ้ำ ตัวแก้ไขของ Blogger อาจตัดคลาส `download` ทิ้ง

## กล่องโค้ด

โค้ดสั้นในประโยคใช้แท็ก `code` ธีมจะทำเป็นชิปเล็กๆ ไม่มีปุ่มคัดลอก

```html
<p>After <code>greet</code> takes <code>name</code>, the caller cannot use it again.</p>
```

กล่องโค้ดใช้ `pre` ครอบ `code` วางแยกจากย่อหน้าในมุมมอง HTML ธีมใส่กรอบแบบหน้าต่างเทอร์มินัลให้เอง และในหน้าบทความจะมีปุ่มคัดลอกมุมขวาบน

```html
<pre><code class="language-rust">fn main() {
    let name = String::from("tempKAEW");
    greet(name);
}</code></pre>
```

คลาส `language-...` บอกภาษาเพื่อใส่สี ไม่ใส่ก็ยังเป็นกล่องโค้ด ใช้ชื่อภาษาของ highlight.js เช่น `language-php` `language-javascript` `language-css` `language-bash` `language-json` `language-xml`

อักขระ `<` กับ `&` ในโค้ดต้องเขียนเป็น `&lt;` กับ `&amp;` ไม่งั้นตัวแก้ไขจะมองเป็นแท็ก HTML

```html
<pre><code class="language-html">&lt;span class="accent"&gt;Kaew&lt;/span&gt;</code></pre>
```

ปุ่มคัดลอกและสีตามภาษาทำงานในหน้าบทความ หน้าเพจทั่วไปได้แค่กรอบโค้ด

## สิ่งที่ธีมจัดให้เอง

ไม่ต้องใส่คลาสเพิ่ม เขียน HTML ปกติได้เลย

- หัวข้อ `h2` มีแถบสีส้มด้านซ้าย `h3` และ `h4` ใช้ขนาดเล็กลง
- ลิงก์ที่ไม่มีคลาส `download` เป็นตัวอักษรสีส้มมีขีดใต้
- รายการ `ul` / `ol`
- รูปมีมุมโค้งและเส้นขอบ
- เส้นคั่น `hr`
- `blockquote`
- โค้ดสั้นและกล่องโค้ด ดูหัวข้อกล่องโค้ดด้านบน
- ตาราง

หัวข้อ `h2` และ `h3` ในบทความถูกใช้ทำสารบัญทางขวาบนจอกว้าง บทความที่เกี่ยวข้องและกล่องผู้เขียนอยู่ท้ายโพสต์ ไม่ต้องเขียนในเนื้อหา
